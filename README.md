# IoT Smart Energy Monitoring System

## Live Demo
https://iot-energy-monitor-glfw.onrender.com

## Overview
This is a Flask-based IoT Smart Energy Monitoring System that helps monitor energy consumption through a modern web dashboard.

## Features
- User Login & Registration
- Dashboard
- Energy Usage Analytics
- Device Management
- Billing
- Reports
- Notifications
- User Profile
- Settings
- PDF Report Export

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Git
- GitHub
- Render

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/IoT-Energy-Monitor.git
cd IoT-Energy-Monitor
pip install -r requirements.txt
python app.py
```
