## Overview
This is a Flask-based IoT Smart Energy Monitoring System that helps monitor energy consumption through a modern web dashboard.

## Features
- User Login & Registration
- Dashboard
- Energy Usage Analytics
- Device Management
- Billing
- Reports
- Notifications
- User Profile
- Settings
- PDF Report Export

## Technologies Used

- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Git
- GitHub
- Render
